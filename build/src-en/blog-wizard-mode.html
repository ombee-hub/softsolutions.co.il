Wizard mode

Softsolutions·February 9, 2022·1 min read

When working with customers, we often want the document creation process to be structured. For example, we may want customers to first fill in the service call header, only then type a description of the issue in the free-text screen, upload an attachment – and finally complete the process in an orderly way.

The "Wizard" flag

That is exactly what the "Wizard" flag in the screen and column management screen is for. When a parent screen is marked with this flag, the system lets users move between the document header and its sub-screens only in display order, opening a new tab at each step with the "Next" button.
