Accessibility statement

We believe in providing equal service to every customer and visitor, and we work to make this website accessible and easy to use for people with disabilities.

Last updated: October 2026

Accessibility level

The website was built in line with the Israeli Equal Rights for Persons with Disabilities (Service Accessibility Adjustments) Regulations, 5773‑2013, and the recommendations of Israeli Standard IS 5568 for web content accessibility at level AA, which is based on the W3C Web Content Accessibility Guidelines (WCAG) 2.0. Accessibility work was carried out as far as possible and is an ongoing effort – we keep testing and improving it.

Adjustments made

  • A consistent page structure with hierarchical headings, labeled navigation regions and a defined page language (Hebrew right-to-left, English left-to-right).
  • Full keyboard navigation: move between elements with Tab, open sub-menus on focus and close panels with Esc. The focused element is clearly outlined.
  • Text alternatives for meaningful images; decorative images are hidden from screen readers.
  • Sufficient color contrast between text and background, and no text presented as an image.
  • A contact form with a label for every field; required fields left empty are highlighted and announced to screen readers.
  • A responsive layout for every screen size – desktop, tablet and phone – with support for browser zoom.
  • Respect for the operating system's "reduce motion" setting, and an option to stop animations from the accessibility menu. The logo carousel pauses on mouse hover.
  • A bilingual website – Hebrew and English – with a language switch on every page.

The accessibility menu

Every page has a fixed accessibility button. It opens a menu where you can turn on:

  • Higher contrast, highlighted links, bigger text and wider text spacing.
  • Increased line height, text aligned to one side and an easy-to-read font (dyslexia support).
  • Paused animations, hidden images and reduced color saturation.
  • A larger mouse cursor, and tooltips that show the text alternatives of images and buttons on hover or focus.

Your settings are saved in your browser and apply to every page until you use "Reset all accessibility settings".

Browsers and assistive technology

The website supports current versions of Chrome, Edge, Firefox and Safari on desktop and mobile. It is built with standard code (semantic HTML and ARIA attributes) that allows it to be used with screen readers.

Known limitations

Despite our efforts, some parts of the website may not be fully accessible:

  • App screenshots contain text inside the image. They have a general text alternative, and their content is described in the page text.
  • The PDF files on the Forms page were carried over from the previous website and may not be fully accessible. You can ask us for an accessible version.
  • External services – the map on the contact page, the demo apps, the support center, the documentation library and the FileSmile website – are not controlled by the Company, and their accessibility is the responsibility of their operators.

Found an accessibility issue?

If you have difficulty using the website or find content that is not accessible, we would like to hear about it and fix it. To help us respond, please include the page address, a description of the problem, and the browser and assistive technology you used.
