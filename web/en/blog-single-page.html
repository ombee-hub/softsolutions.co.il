Working in single-page mode

Softsolutions·February 9, 2022·1 min read

Sometimes we want our customers to work with Priority without sub-screens, in a single-page layout instead. The builder lets you treat the document header, free-text screens and attachments screen as one unit and display them on a single page.

This layout is especially useful for landing pages, opening service calls, task diaries and more.

1 Build the header screen

Building a single-page screen starts like any other screen in the Portal Builder: choose the Priority screen, assign it to a menu and select the columns to display on the site.

In this example we chose the service calls screen and selected the Details, Call Type and Customer Diagnosis Code columns for display.

2 Link the free-text and attachments sub-screens

In the "Sub-screen management" sub-screen, link the screens to display. For the service call, for example, we selected the "Problem description" and "Attachments" sub-screens.

Note: Each of these screens must be defined separately in the "Screen and column management" screen, where you also choose which fields the customer sees.

At this stage, the service call page looks like any screen that shows its sub-screens as tabs:

3 Set up the single-page layout

Go back to the service call's "Sub-screen management" sub-screen. Some screens have a value in the "Sub-screen type" column – T for free-text screens and F for attachment screens. For these screens you can check the "Display inline" flag.

Every sub-screen marked with this flag moves to the main page, below the header screen, and is no longer shown as a tab:

Notes

  • You can combine this technique with other sub-screens – for example, show the call's free text on the opening page while other sub-screens, such as spare parts or labor, remain tabs.
  • In the current version, inline display is supported for free-text and attachment screens only.

Good luck,
